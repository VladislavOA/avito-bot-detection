# Детекция ботов по поведению в 24-часовом окне (Avito Challenge)

Репозиторий содержит финальное, полностью воспроизводимое решение задачи классификации сессий пользователей (боты vs люди) по 24-часовым окнам наблюдения.

- **Целевая метрика соревнования:** $P@R \ge 0.7$ (Precision при Recall $\ge 70\%$)
- **Результат финальной модели на Holdout:** **`0.8619`** (90% CI: `[0.778, 0.914]`)
- **Результат на 5-Fold Walk-Forward CV:** **`0.8614 ± 0.0493`**
- **Финальная модель:** Одиночный **CatBoost** с целевым upweighting мобильных ботов ($w = 1.25$) и бэггингом по 5 сидам.

---

## 1. Быстрый старт: запуск финального решения

Главная точка входа для проверяющего — ноутбук **`solution.ipynb`**.

Ноутбук полностью автономен, содержит подробные комментарии, визуализации и запускается от начала до конца («Run All») за **2–4 минуты**:

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск Jupyter Notebook
jupyter notebook solution.ipynb
```

При запуске ноутбук:
1. Загружает данные и выполняет проверки базовых инвариантов.
2. Подготавливает 76 признаков (использует кэш `data/features_train.parquet` или пересчитывает из `data/events.csv.gz`).
3. Валидирует лестницу моделей на 5-фолдовом Walk-Forward CV.
4. Обучает финальный CatBoost с 5-seed бэггингом на всём `train.csv`.
5. Генерирует и сохраняет итоговый файл **`submission.csv`**.
6. Проводит автоматический assert-тест по всем 6 правилам формата сабмишна.

## 3. Ключевые результаты EDA и архитектурные решения

### 3.1. Ловушка утечки данных (Data Leakage Trap)
- В сырых данных обучающей выборки обнаружено 40 779 событий, произошедших **после** `window_end_ts`.
- Среди них содержались **все 100% (7 928) событий показа капчи (`captcha_shown`)**.
- В тестовой выборке постоконные события отсутствуют полностью.
- **Решение:** Фильтрация событий строго по полуинтервалу:
  $$window\_start\_ts \le event\_ts < window\_end\_ts$$
  Любые постоконные признаки и события капчи внесены в строгий Blacklist.

### 3.2. Карта 4 архетипов ботов
На позитивном классе обучена кластеризация ($k$-Means на стандартизованных признаках), выявившая 4 диаметрально противоположных профиля:
1. **Кластер 0 (18.0%):** Агрессивный краулер (глубокая пагинация $>15$, высокая частота запросов).
2. **Кластер 1 (4.9%):** Прямой HTTP-скрипт (`curl`, `Scrapy`, `python-requests`).
3. **Кластер 2 (32.7%):** Мобильный эмулятор / парсер контактов (только мобильные устройства, эмуляция тапов).
4. **Кластер 3 (44.4%):** Stealth Web бот (десктоп, эмуляция мыши, умеренная скорость).

### 3.3. Физика курсора (Desktop vs Mobile)
- На мобильных устройствах координаты курсора мыши отсутствуют физически (`pointer_x/y` = NaN как у людей, так и у ботов).
- На десктопе боты Кластера 3 маскируются под людей, но их выдаёт координатная дисперсия (`pointer_x_std`, `pointer_y_std`) и отсутствие микродвижений.

## 4. Фичеинжиниринг: 76 лучших признаков

Финальный фичсет включает **76 признаков** (73 числовых, 3 категориальных):
- **Блок A (Активность):** `n_events_total`, `event_freq_per_hour_mean/max`, `active_hours_share`, `hourly_entropy`.
- **Блок B (Возраст куки):** `cookie_age_hours`.
- **Блок C (Временная динамика):** `dt_median_sec`, `dt_mean_sec`, `dt_iqr_sec`, доля быстрых переходов ($\Delta t < 1$с), отношение числа локаций к категориям `loc_to_cat_ratio`.
- **Блок D (Координаты мыши на десктопе):** `pointer_x_std`, `pointer_y_std`, `pointer_step_median`, `pointer_fill_rate_desktop`.
- **Блок E (User-Agent и платформа):** флаг парсер-библиотек `is_known_scraper_lib`, `ua_os_family`, `ua_browser_family`, `platform_bucket`.
- **Блок F (Каталог и со-визитация — ТОП-1 ДРАЙВЕР):** `n_covisitors_total_mean`, `search_page_max`, `search_page_mean`, `deep_pagination_flag`.
- **Блок G (Мобильные взаимодействия):** `is_mobile_only`, `has_desktop_events`, `mobile_contact_ratio`.
- **Блок I (Unsupervised Anomaly Score):** `anomaly_score_iforest` от модели `IsolationForest(n_estimators=150, contamination=0.08)`.

> **Исключённые признаки:** Блок H (цепочки переходов между экранами) удалён в ходе абляции, так как являлся шумовым дубликатом Блока F (его исключение повысило Holdout с 0.8392 до 0.8516). Также удалены 7 признаков с 0 Gain.

## 5. Валидационная схема и лестница моделей

### 5-Fold Walk-Forward Time-Series Split
Данные разбиваются на 5 временных окон с расширяющимся обучением:
- **Фолд 0:** Train дни 0–5 $\to$ Val дни 6–7
- **Фолд 1:** Train дни 0–7 $\to$ Val дни 8–9
- **Фолд 2:** Train дни 0–9 $\to$ Val дни 10–11
- **Фолд 3:** Train дни 0–11 $\to$ Val дни 12–13
- **Фолд 4 (Holdout):** Train Неделя 1 $\to$ Val Неделя 2

### Лестница бейзлайнов и выбор CatBoost

| Уровень | Модель / Конфигурация | 5-Fold CV Mean | CV Std | Описание |
| :---: | :--- | :---: | :---: | :--- |
| **Level 0** | Random Baseline | 0.0844 | 0.0022 | Равномерный случайный скор (базовый уровень) |
| **Level 1** | Rule-based Heuristic | 0.1306 | 0.0089 | Z-score эвристика по топ-признакам |
| **Level 2** | Logistic Regression | 0.2159 | 0.0274 | Линейная модель на числовых признаках |
| **Level 3** | LightGBM Baseline | 0.8409 | 0.0462 | Чистый фичсет A..G |
| **Level 3** | XGBoost Baseline | 0.8377 | 0.0531 | Чистый фичсет A..G |
| **Level 3** | **CatBoost Baseline** | **0.8614** | **0.0493** | Нативная обработка категорий, ordered boosting |
| **Final** | **CatBoost (Upweight + 5 Seeds)** | **0.8612** | **0.0566** | **Holdout: 0.8619** (Recall Cl.2 вырос с 53.9% до 57.8%) |

### Почему CatBoost, а не сложный ансамбль?
1. **Статистическая неразличимость:** Парный bootstrap-тест (1 000 итераций) показал $90\%$ CI разности между ансамблем и CatBoost $[-0.0088, +0.0173]$ (интервал включает 0, $P(\text{Blend} > \text{CB}) \approx 50.3\%$). Ансамбль не имеет статистического преимущества.
2. **Бритва Оккама:** Одиночный CatBoost втрое быстрее обучается, не требует сложной синхронизации one-hot кодирования и гарантирует 100% стабильность и воспроизводимость.

## 6. Финальные стресс-тесты и диагностика

- **Стресс-тест без ТОП-1 признака (`n_covisitors_total_mean`):** метрика удерживается на уровне **`0.7520`** (модель не хрупкая, её страхуют временные дельты, параметры мыши и anomaly score).
- **LOCO-тест (Leave-One-Cluster-Out):** незнакомые боты Кластеров 0 и 1 детектируются на $88–100\%$ zero-shot благодаря аномальному поведению.
- **Верификация сабмишна:**
  - Ровно 4 909 строк;
  - Порядок `cookie_id` строго соответствует `sample_submission.csv`;
  - Пропуски (NaN) отсутствуют;
  - Значения скоров в диапазоне $[0.00115, 0.99421]$;
  - **4 909 из 4 909 скоров строго уникальны** (нулевой риск дискретных tie-групп).
